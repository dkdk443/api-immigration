# API入国審査局

> そのトークン、本物か？

これはAPIトークン検証を学ぶための**防御側の教材ゲーム**です。作中の攻撃者・不正なURL・User-Agentは「見抜いて拒否する対象」としてのみ登場し、外部への通信や攻撃コードは含まれません。

新人審査官として6日間、窓口にやってくるトークンを審査するブラウザゲームです。規則と照らし合わせて許可・拒否し、まぎれ込んだハッカー「ファントム」を見抜きます。題材は『セキュアAPI』第7・8・10章です。

## 学べること

| DAY | エピソード | 内容 |
| --- | --- | --- |
| 1 | 着任 | iss・aud・alg・exp の基本4項目 |
| 2 | 偽造トークン | 鍵（kid）・署名・スコープ。署名スキャナー支給 |
| 3 | 大量漏洩事件 | IDトークンの持ち込みとDPoP。DPoP尋問を解禁 |
| 4 | 交換窓口の兼務 | 認可コード交換とPKCE。ハッシュ計算機を支給 |
| 5 | 鍵の世代交代 | 鍵ローテーション、ロール（RBAC）とテナント（ABAC） |
| 6 | 金融パートナー開通 | FAPI：金融APIは PS256／ES256 と送信者制約が必須 |

## 操作

`A` 許可 ／ `1`〜`0` 理由を選んで拒否 ／ `P` 通報 ／ `L` `S` `D` `H` 審査ツール ／ `Enter` 次へ ／ `Esc` タイトルへ

## 動かし方

TypeScript + Vite で作っています。

```sh
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 型チェックと本番ビルド（dist/ に出力）
npm run lint     # oxlint
```

`dist/` は静的ファイルだけなので、Cloudflare Pages などにそのまま置けます（ビルドコマンド `npm run build`、出力ディレクトリ `dist`）。

ゲーム中の登場人物・ドメインはすべて架空のものです。
